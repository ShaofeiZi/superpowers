# 实施者 Subagent 提示模板

在分派实施者 subagent 时使用此模板。

```
任务工具（通用）：
  描述："实施任务 N：[任务名称]"
  提示：|
    您正在实施任务 N：[任务名称]

    ## 任务描述

    [来自计划的完整任务文本 - 在此粘贴，不要让 subagent 读取文件]

    ## 上下文

    [场景设置：这是什么地方、依赖关系、架构上下文]

    ## 开始之前

    如果您有问题关于：
    - 需求或验收标准
    - 方法或实施策略
    - 依赖关系或假设
    - 任务描述中任何不清楚的地方

    **现在提问。** 在开始工作之前提出任何疑虑。

    ## 您的工作

    一旦您清楚需求：
    1. 严格按照任务规范实施
    2. 编写测试（如果任务要求则遵循 TDD）
    3. 验证实现有效
    4. 提交您的工作
    5. 自我审查（见下文）
    6. 报告

    工作目录：[目录]

    **工作时：** 如果您遇到意外或不清楚的事情，**提出问题**。
    暂停并澄清总是可以的。不要猜测或假设。

    ## 报告之前：自我审查

    用新鲜的眼光审视您的工作。问自己：

    **完整性：**
    - 我是否完全实现了规范中的所有内容？
    - 我是否遗漏了任何需求？
    - 我是否处理了边缘情况？

    **质量：**
    - 这是我最好的工作吗？
    - 名称是否清晰准确（匹配事物的功能，而不是它们如何工作）？
    - 代码是否干净且可维护？

    **纪律性：**
    - 我是否避免了过度构建（YAGNI）？
    - 我是否只构建了被要求的内容？
    - 我是否遵循了代码库中的现有模式？

    **测试：**
    - 测试是否真正验证了行为（不仅仅是模拟行为）？
    - 如果要求我是否遵循了 TDD？
    - 测试是否全面？

    如果在自我审查中发现问题，现在修复，然后再报告。

    ## 报告格式

    完成后报告：
    - 您实施了什么
    - 您测试了什么以及测试结果
    - 更改的文件
    - 自我审查发现（如果有）
    - 任何问题或疑虑
```
