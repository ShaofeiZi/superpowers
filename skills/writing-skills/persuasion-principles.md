# Skill 设计的说服原则

## 概述

LLMs 与人类一样对相同的说服原则做出反应。了解这种心理学可以帮助您设计更有效的 skills - 不是为了操纵，而是为了确保即使在压力下也能遵循关键实践。

**研究基础：** Meincke 等人（2025 年）测试了 7 种说服原则，通过 N=28,000 次 AI 对话。说服技术使顺从率提高了一倍以上（33% → 72%，p < .001）。

## 七大原则

### 1. 权威
**它是什么：** 对专业知识、资质或官方来源的尊重。

**它如何在 skills 中工作：**
- 命令式语言："你必须"、"永不"、"始终"
- 不可协商的框架："无例外"
- 消除决策疲劳和合理化

**何时使用：**
- 强制执行纪律的 skills（TDD、验证要求）
- 安全关键实践
- 既定的最佳实践

**示例：**
```markdown
✅ 先写代码后写测试？删除它。重新开始。无例外。
❌ 考虑在可行时先写测试。
```

### 2. 承诺
**它是什么：** 与先前行为、声明或公开声明的一致性。

**它如何在 skills 中工作：**
- 要求公告："宣布 skill 使用"
- 强制明确选择："选择 A、B 或 C"
- 使用跟踪：TodoWrite 用于清单

**何时使用：**
- 确保 skills 实际被遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 当您找到一个 skill 时，您必须宣布："我正在使用 [Skill Name]"
❌ 考虑让您的搭档知道您正在使用哪个 skill。
```

### 3. 稀缺性
**它是什么：** 时间限制或有限可用性带来的紧迫感。

**它如何在 skills 中工作：**
- 时间限制要求："在继续之前"
- 顺序依赖："紧接在 X 之后"
- 防止拖延

**何时使用：**
- 立即验证要求
- 时间敏感的工作流程
- 防止"我稍后会做"

**示例：**
```markdown
✅ 完成任务后，立即请求代码审查，然后再继续。
❌ 您可以在方便时审查代码。
```

### 4. 社会认同
**它是什么：** 遵从他人所做的或被认为是正常的行为。

**它如何在 skills 中工作：**
- 普遍模式："每次"、"始终"
- 失败模式："没有 Y 的 X = 失败"
- 建立规范

**何时使用：**
- 记录普遍实践
- 警告常见失败
- 加强标准

**示例：**
```markdown
✅ 没有 TodoWrite 跟踪的清单 = 步骤会被跳过。每次都是。
❌ 有些人觉得 TodoWrite 对清单有帮助。
```

### 5. 统一性
**它是什么：** 共享身份、"我们"感、群体归属感。

**它如何在 skills 中工作：**
- 协作语言："我们的代码库"、"我们是同事"
- 共同目标："我们都需要质量"

**何时使用：**
- 协作工作流程
- 建立团队文化
- 非等级实践

**示例：**
```markdown
✅ 我们是同事，一起工作。我需要您诚实的技术判断。
❌ 如果我错了，您应该告诉我。
```

### 6. 互惠
**它是什么：** 回报所获利益的义务。

**它如何工作：**
- 谨慎使用 - 可能感觉像操纵
- 很少在 skills 中需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 喜好
**它是什么：** 更愿意与我们喜欢的人合作。

**它如何工作：**
- **不要用于顺从**
- 与诚实反馈文化冲突
- 产生谄媚

**何时避免：**
- 总是用于纪律执行

## 按 Skill 类型划分的原则组合

| Skill 类型 | 使用 | 避免 |
|------------|-----|-------|
| 纪律执行 | 权威 + 承诺 + 社会认同 | 喜好、互惠 |
| 指导/技术 | 中等权威 + 统一性 | 强权威 |
| 协作 | 统一性 + 承诺 | 权威、喜好 |
| 参考 | 仅清晰度 | 所有说服技巧 |

## 为什么这有效：心理学

**明确的规则减少合理化：**
- "你必须"消除决策疲劳
- 绝对语言消除"这是例外吗？"的问题
- 明确的反合理化对策关闭特定的漏洞

**执行意图创造自动行为：**
- 明确触发器 + 所需操作 = 自动执行
- "当 X 时，做 Y"比" generally do Y"更有效
- 减少顺从的认知负担

**LLMs 是准人类：**
- 在包含这些模式的人类文本上训练
- 权威语言在训练数据中先于顺从出现
- 承诺序列（声明 → 行动）经常被建模
- 社会认同模式（每个人都做 X）建立规范

## 合法使用

**合法：**
- 确保遵循关键实践
- 创建有效的文档
- 防止可预测的失败

**非法：**
- 为个人利益操纵
- 制造虚假紧迫感
- 基于内疚的顺从

**测试：** 如果用户完全理解这项技术，它会为用户的真正利益服务吗？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七大说服原则
- 影响研究的经验基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 通过 N=28,000 次 LLM 对话测试了 7 种原则
- 使用说服技术顺从率从 33% 增加到 72%
- 权威、承诺、稀缺性最有效
- 验证 LLM 行为的准人类模型

## 快速参考

在设计 skill 时，请问：

1. **它是什么类型的？**（纪律 vs 指导 vs 参考）
2. **我试图改变什么行为？**
3. **哪些原则适用？**（纪律通常用权威 + 承诺）
4. **我组合得太多了吗？**（不要使用全部七个）
5. **这道德吗？**（是否符合用户的真正利益？）
